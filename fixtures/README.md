# fixtures

소스 파서 테스트용 응답 샘플.

| 파일 | 출처 |
|---|---|
| `*/spec-sample.json` | 공식 명세 페이지의 **예시 값으로 만든** 샘플 (실제 응답 아님). 필드명은 명세 그대로 |
| `*/live-YYYYMMDD.json` | `pnpm sync:probe`가 저장한 **실제 응답** (키 발급 후). 커밋해서 파서 회귀 테스트에 쓴다 |

실제 응답을 받으면 `docs/sources/*.md`의 "아직 확인 못 한 것"을 확인하고, 파서와 테스트를 실제 응답 기준으로 고친다.
실제 응답에 개인 연락처(담당자 전화 등)가 있어도 공개 공고 정보라 그대로 둔다. 인증키는 응답에 들어가지 않는다.
| `boards/*-list-YYYYMMDD.html` | 공고 게시판 목록 페이지 원본 (게시판 소스 `readListPage` 테스트). jbtp·btp는 글 링크가 보통 주소, mss는 스크립트로 글을 여는 게시판 |
