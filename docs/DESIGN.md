## 1. 방향

| | |
|---|---|
| 제품 | 베어링 팀이 정부지원사업 공고를 우리에게 맞는 순으로 보고, 초안을 받아 리뷰하는 내부 툴 |
| 성격 | 먼저 챙겨주는, 차분한, 가벼운 |
| 세계 | 월요일 아침 팀 책상 위 플래너. 핵심은 "마감까지 남은 시간". 맑은 아침 하늘 블루~라벤더 |
| 모먼트 | 홈의 "가장 잘 맞는 공고" 히어로 카드(그라데이션), 적합도 숫자 |
| 시그니처 | **접수 기간 타임라인 바 + 오늘 위치 점.** D-7 이내면 주황으로 바뀐다 |

톤 한 줄: 밝고 부드럽고 매끄러운 **"친근한 프리미엄"**. 잘 만든 앱(토스, 애플, 글로벌 SaaS)처럼 정돈되고, 차갑지 않고 쉬워 보인다.

## 2. 반드시 지킬 규칙

1. **그라데이션은 화면당 한 곳.** 홈에서는 히어로 카드만. 버튼, 테두리, 내비, 다른 카드 배경에 쓰지 않는다. 그라데이션 글자 금지. 글로우·블롭·구슬 장식 금지
2. **포인트 색은 하나(`--color-accent`)**. 주요 버튼, 선택 상태, 높은 점수에만. 상태 색은 칩·점·바에서만
3. **기술력은 스타일이 아니라 완성도로.** 모노스페이스 장식, 터미널, 모눈, 코드 블록 장식 금지
4. 이모지를 아이콘으로 쓰지 않는다 → lucide, stroke 2, 16/18px
5. 대문자+넓은 자간 라벨, 제목 위 작은 머리말 배지(`✨ NEW`), 섹션 번호(01/02) 금지
6. 문구: 느낌표 금지. 버튼은 "동사+목적어"(초안 이어 쓰기, 새 공고 가져오기). 짧은 라벨 끝 마침표 금지. 과장어(혁신적인, 원스톱, AI 기반 남발) 금지
7. 극단 톤 금지: 전체 다크 페이지, 아무 색 없는 새하얀 페이지 둘 다 피한다. 바탕은 `--color-bg`
8. 한글: `word-break: keep-all`, 본문 줄간격 1.6~1.75, 작은 글자에 음수 자간 금지(제목만 -0.02~-0.04em)

## 3. 토큰 요약 (값은 tokens.css)

### 색
- 바탕 `#F3F5FA` / 면 `#FFFFFF` / 보조 면 `#F6F7FB`
- 글자: 주요 `#191C24`, 보조 `#4A5060`, 흐림 `#636979` (본문용 최소). `#9AA0AE`는 아이콘·장식 전용
- 테두리: `rgba(25,28,36,0.06)` 가는 선. 그림자는 작고 색 없이. 히어로만 블루 그림자
- 포인트: `#2D5BE3` (hover `#1E46C2`, soft `#EEF2FF`)
- 히어로 그라데이션: `linear-gradient(130deg, #3A63F5 0%, #6A5CF6 55%, #9457D2 100%)`
  - 캔버스 시안의 끝 색 `#B66FE0`은 흰 글자 대비가 3.3:1이라 `#9457D2`(4.6:1)로 조정했다. 히어로 위 작은 글자는 반투명이 아니라 100% 흰색

### 간격·라운드
- 4px 단위. 페이지 패딩 40(위) 48(좌우), 섹션 사이 32, 카드 사이 20, 히어로 패딩 32, 카드 패딩 24, 리스트 행 20×24
- 라운드: 히어로 28, 카드·리스트 컨테이너 24, 점수 배지 16, 내비 아이템 12, 버튼·칩·입력·탭 완전 둥글게

## 4. 컴포넌트 명세

### Button
| 변형 | 모양 | 용도 |
|---|---|---|
| primary | bg accent, 흰 글자, h48(큰)/h44, 알약형, 700 | 화면의 주요 행동 1개 |
| ink | bg `#191C24`, 흰 글자, h44, 아이콘+텍스트 | 헤더의 "새 공고 가져오기" |
| soft | bg accent-soft, 글자 accent, h36 | 카드 안 보조 행동(초안 만들기) |
| ghost-on-hero | 투명, 흰 1px(40%) 테두리, 흰 글자 | 히어로 안 보조 행동 |
| on-hero | 흰 바탕, 글자 `#2D3FB8` | 히어로 안 주요 행동 |
| text link | accent, 13~14px 600 | "열기", "프로필 수정하기" |

상태: hover는 배경 한 단계 진하게(`--dur-fast`), active `scale(0.98)`, focus-visible 2px accent 링(오프셋 2), disabled opacity .45 + `cursor: not-allowed`, loading은 스피너+텍스트 유지(폭 고정).
화면당 주요 버튼 1개 + 보조 최대 1개.

### ScoreBadge (적합도)
- 리스트: 48×48, 라운드 16, 숫자 17/800. 85+ = accent-soft/accent, 70–84 = `#F3F4F8`/`#3A3F4C`, 70 미만 = `#F3F4F8`/`#636979`
- 히어로: 배지 없이 숫자 56/800 흰색 + 아래 "적합도" 13/600
- 보조 카드: 인라인 "적합도 **88**"(숫자만 accent 굵게)
- 점수 없음(하드필터 탈락): 숫자 대신 표시하지 않고 칩 "제외" + 메타에 사유

### TimelineBar (시그니처)
- 트랙 4px(리스트)/6px(히어로), 라운드 full, 트랙색 `--color-track` (히어로는 흰 24%)
- 채움 = 접수 시작~오늘 비율. 오늘 위치에 점(리스트 10px, 히어로 14px), 점 둘레 3~4px 링(바탕색 또는 흰 28%)
- 위 줄: 왼쪽 기간 "11.20 – 12.08"(캡션, 흐림), 오른쪽 D-day(캡션 700)
- 색 규칙:
  - 접수 중, D-8 이상: accent
  - 접수 중, D-7 이내: `--color-urgent` 바·점, D-day 글자 `--color-urgent-text`
  - 접수 전: 채움 0, 점은 시작점에 `--color-timeline-idle`, D-day 자리에 "시작 D-8"
  - 마감 지남: 표시 안 함(리스트에서 빠지거나 지원 이력으로 이동)
- D-day는 **KST 자정 기준**으로 계산. 당일은 "오늘 마감"
- 접근성: 바는 `aria-hidden`, D-day 텍스트가 정보를 전달

### StatusChip
- h28, 패딩 0 12, 12/600, 알약형. 색은 3절 표. 리스트에서는 오른쪽 96px 칸에 오른쪽 정렬

### Card
- 기본: 면 흰색, 1px border, 라운드 24, 패딩 24, 그림자 없음(또는 `--shadow-card`)
- 카드 안에 카드 금지

### FocusHeroCard (홈 전용, 그라데이션 유일)
- 패딩 32, 라운드 28, `--gradient-hero`, `--shadow-hero`, 내부 세로 간격 24
- 구성(위→아래): [라벨 "가장 잘 맞는 공고" + 공고명 28 + 기관·지원 규모] ↔ 오른쪽 [점수 56 + "적합도"] / 맞는 이유 칩(최대 3, 체크 아이콘, 흰 18% 배경) / TimelineBar(히어로) / [on-hero 버튼 "초안 이어 쓰기"(상태에 따라 "초안 만들기"/"리뷰 보기")] [ghost 버튼 "공고문 보기"] [진행 텍스트 "사업계획서 초안 6/9 섹션 완료"]
- 상태별 주요 버튼 문구: new/triage → "초안 만들기", drafting → "초안 이어 쓰기", review → "리뷰 보기"

### AnnouncementRow (리스트 행)
- 전체가 링크(`<a>`), 패딩 20×24, 행 사이 1px 구분선, flex-wrap
- 칸: ScoreBadge(48) / 공고명 16 + 메타 13 (flex 3, min 260) / TimelineBar (flex 2, min 200) / StatusChip (96) / chevron 18
- hover: 배경 `#F8F9FC`, chevron `--color-text-secondary`
- 제외 행: opacity .55, 메타에 제외 사유

### Segmented Tabs (필터)
- 트랙 `--color-surface-sunken`, 패딩 4, 알약형. 탭 h36, 선택 탭 흰 배경+`--shadow-sm`+600, 비선택 투명+500 보조색
- 라벨에 개수: "전체 12", "새 공고 4", "진행 중 3", "제외 5"
- `role="tablist"`/`tab`, 화살표 키 이동

### Sidebar
- 폭 232~260, 흰 면, 오른쪽 1px border, 패딩 28×16
- 위: 로고 마크(32, 라운드 10, accent 단색, 흰 아이콘) + 툴 이름 15/700 + "베어링 내부 툴" 12
- 내비 아이템: h44, 라운드 12, 아이콘18+라벨14. 현재 = accent-soft 배경 + accent 글자 600. 카운트 배지(22, 회색) 선택
- 메뉴: 홈 / 전체 공고 / 초안·리뷰(리뷰 대기 수) / 지원 이력 / 회사 프로필
- 아래: 회사 카드(보조 면, 라운드 16): 회사명, "SW 스타트업 · 부산 · 업력 1년 미만"(프로필에서 계산), "프로필 수정하기" 링크

### Search input
- h44, 폭 240, 알약형, 흰 바탕, 1px border-strong, 왼쪽 돋보기 16, placeholder "공고명, 기관 검색". 숨김 label 필수

### Avatar
- 28(카드)/24(보드)/32(헤더), 원형, 이니셜 11/700, 배경 accent-soft-2 또는 `#EEF0F6`

### 빈 상태·로딩·오류
- 로딩: 리스트 행 모양 스켈레톤(배지·두 줄·바), 은은한 shimmer 1회성 아님 → 로딩 중에만 반복 허용
- 빈 상태(맞는 공고 0): 일러스트 없이 한 문장 + 행동 버튼. 예: "이번 주에 새로 맞는 공고가 없어요" + [새 공고 가져오기]
- 소싱 오류: 헤더 아래 얇은 알림 줄(주황 soft 배경) "기업마당 불러오기에 실패했어요 · 다시 시도"
- 【확인 필요】 표시(초안): 배경 `#FFF6D6`, 글자 `#7A5A00`, 라운드 6, 클릭하면 회사 프로필 해당 필드로 이동

### 5.2 전체 공고
- 홈 리스트와 같은 AnnouncementRow. 위에 검색 + 필터(상태, 소스, 분야, 마감 범위, 점수 범위) + 정렬(점수/마감)
- 헤드라인: "공고 N건" + 마지막 소싱 시각 "오늘 오전 9시에 가져왔어요"

### 5.3 공고 상세 (A안 상세 패널을 페이지로 확장)
- 왼쪽(넓게): 공고 요약, 지원 내용·대상·기간, 원문 링크, 첨부파일 목록(다운로드)
- 오른쪽 패널(340~380): 적합도 링(그라데이션 링은 **히어로가 없는 이 화면의 유일한 그라데이션**), "맞는 이유"(체크 아이콘 accent), "확인 필요"(주황 원 아이콘), 제출 서류 체크리스트(준비됨 초록/초안 n/m 보라/미첨부 흐림), 주요 버튼 상태별(초안 만들기 등) + 보조 "제외하기"(사유 입력 모달)
- A안 원본: `design/source/A-Refined.dc.html`

### 5.4 초안·리뷰 보드 (C안 참고) — `design/reference/board-c.html`
- 칸반 4열: 추천됨 / 초안 작성 / 리뷰 / 제출 완료. 열 헤더 = 상태 점 + 이름 + 개수
- 카드: 공고명 15/700 + 점수, 기관(+초안 진행 "6/9"), 타임라인 바(라벨 없이) + D-day + 담당 아바타
- 앱 안에서는 사이드바 레이아웃을 유지한다. C안의 상단 파스텔 그라데이션 배경과 글래스 열은 **이 화면의 모먼트로만** 사용 가능(홈과 동시에 보이지 않으므로 화면당 한 곳 규칙 충족). 단순하게 가려면 흰 열 + 회색 바탕
- 드래그로 상태 변경(서버에서 전이 규칙 검증, 실패 시 원위치 + 토스트)

### 5.5 초안 에디터 (미디자인 — 이 원칙으로)
- 왼쪽 섹션 목차(진행 체크), 가운데 섹션 에디터(최대 폭 720, 본문 15/1.75), 오른쪽 코멘트·리뷰 패널
- 섹션 헤더: 제목 + 분량 카운터("812 / 1,000자", 초과 시 주황) + [다시 쓰기 ▾] 메뉴(더 구체적으로/짧게/평가 기준 반영)
- 【확인 필요】 하이라이트, 상단에 "확인 필요 3곳" 요약 칩
- 상단 바: 공고명, 상태 칩, 리뷰어 지정, [내보내기 ▾] (DOCX/PDF/MD), 주요 버튼 "리뷰 요청하기" 또는 "제출 완료로 표시"

### 5.6 회사 프로필 (미디자인)
- 탭: 기본 정보 / 아이템 카드 / 문서 라이브러리 / 제외 규칙
- 폼은 2열(데스크톱) → 1열(모바일), 라벨 위, 입력 h44 라운드 12(폼 입력은 알약형 대신 12), 도움말 13 흐림
- 아이템 카드: 카드 그리드(2열), 카드에 문제/해결/고객/차별점 미리보기

## 6. 움직임
- 하나의 이징 `--ease`. 호버 120ms, 전환 200ms
- 첫 로드에 히어로·카드만 한 번 페이드+8px 올라오기(320ms). 스크롤 등장 연출, 패럴랙스, 튕기는 스프링, 반복 펄스 금지
- 탭 전환은 리스트 크로스페이드 200ms
- `prefers-reduced-motion`이면 모든 이동 제거

## 7. 반응형
- ≥1200: 사이드바 고정 + 본문
- 768~1199: 사이드바 아이콘만(폭 72) 또는 상단 바로 전환
- <768: 사이드바 → 하단 탭바(홈/공고/보드/프로필), 히어로·보조 카드 1열 스택, 리스트 행은 배지+제목 한 줄, 그 아래 타임라인 바 전체 폭, 칩은 제목 옆. 버튼 전체 폭, 터치 44px 이상
- 보드: 가로 스크롤(열 폭 280 고정)
